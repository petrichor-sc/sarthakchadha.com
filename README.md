## Communication Systems and Octave tutorials

The ready-to-publish website is in the root `docs/` folder. Read `START_HERE.txt` for the replacement and publishing steps. The app's source is in `apps/communication-systems/`; `npm run build:all` builds it and updates the published copy in `docs/projects/communication-systems/`. After app source changes, install its dependencies with `npm ci --prefix apps/communication-systems` before running that full build. Commit both source and root `docs/` output. The custom-domain file is retained in `public/CNAME` and copied during portfolio builds.
