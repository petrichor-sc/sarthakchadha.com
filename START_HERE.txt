SARTHAK CHADHA — PORTFOLIO FOR GITHUB PAGES

The complete website is ready in docs/.
Your supplied Communication Systems application is included and opens directly
from its project card. You do not need Node.js to upload this first version.

1. Extract this ZIP.
2. Create a NEW public GitHub repository named sarthak-portfolio.
3. Upload the CONTENTS of the sarthak-portfolio folder to that repository.
   The repository root should contain docs, apps, public, src, scripts,
   package.json and README.md.
4. Open the repository's Settings > Pages.
5. Choose Deploy from a branch > main > /docs > Save.
6. After the deployment finishes, use Visit site to test the portfolio.
7. In Settings > Pages > Custom domain, enter sarthakchadha.com and Save.
8. Follow GITHUB_AND_IONOS_SETUP.md for the .com DNS records, HTTPS and the
   .de, .global and .store forwarding settings (including www).

The canonical public address will be https://sarthakchadha.com/.
The other personal domains should forward to that address through IONOS.
Essentia Resonance remains its own website, linked from this portfolio.

Your IONOS screenshot confirms the domain spelling: sarthakchadha.
No GitHub account settings, DNS records or forwarding settings have been changed
by creating this package. They still need to be applied in your accounts.
