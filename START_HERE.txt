UPDATE YOUR EXISTING WEBSITE

1. Extract this ZIP and open the sarthakchadha.com-main folder.
2. Copy its CONTENTS into your existing website repository root.
   At the root you should see docs, apps, public, src, scripts and package.json.
   Avoid adding another enclosing folder.
3. Include the updated root docs/ folder, not only public/ or src/.
4. Commit and push the changes to the branch your existing website publishes.
5. For the existing branch-based GitHub Pages setup, keep the publishing
   folder set to main > /docs and retain your current custom domain.
6. After deployment finishes, check:
   https://sarthakchadha.com/projects/industrial-robotics/
   https://sarthakchadha.com/talks/#robotics-supervision
   https://sarthakchadha.com/#talks
   https://sarthakchadha.com/talks/
   https://sarthakchadha.com/#featured
   Hard-refresh with Ctrl+Shift+R if an old version is cached.

No local Node.js build is required to publish the supplied docs/ folder.
