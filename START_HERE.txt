UPDATE YOUR EXISTING WEBSITE

1. Extract this ZIP and open the sarthakchadha.com-updated folder.
2. Copy its CONTENTS into your existing website repository's root.
   At the repository root you should see docs, apps, public, src, scripts,
   package.json and README.md. Avoid adding another enclosing folder.
3. Include ALL of the root docs/ folder in the update. In particular:
   docs/projects/communication-systems/index.html
   docs/projects/communication-systems/assets/
   Replacing only apps/communication-systems/ is not enough.
4. Commit and push the changes to the branch your existing site publishes.
5. For the branch-based setup documented in this project, keep GitHub Pages
   set to Deploy from a branch > main > /docs. Keep the existing custom domain.
6. Wait for the Pages deployment to finish successfully, then open:
   https://sarthakchadha.com/projects/communication-systems/
7. If the old layout remains after deployment, hard-refresh with Ctrl+Shift+R.
   The new app includes Explore transmitter, Explore receiver, and
   Inside the software receiver.

WHY THE OLD APP APPEARED

The app project in apps/ already matched the new project. The public-facing
copy under the root docs/ directory still referenced an older JavaScript
bundle. The missing step was integrating the app export into the website.

FUTURE UPDATES

After replacing the app with a project that includes a current built docs/
folder, run this from the WEBSITE repository root:

  npm run build

After editing app source, install its dependencies and rebuild both parts:

  npm --prefix apps/communication-systems ci
  npm --prefix apps/communication-systems test
  npm run build:all

Then commit and push the updated source AND root docs/ output.

See DIAGNOSIS_AND_UPDATE.md for the evidence and README.md for build details.
