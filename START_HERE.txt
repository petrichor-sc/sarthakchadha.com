SARTHAKCHADHA.COM — OCTAVE TUTORIALS UPDATE — 2 NOVEMBER 2026

This is the complete website, already built and ready to publish.
The ZIP contains one sarthakchadha.com folder. Inside it are docs, apps,
public, src, scripts and package.json.

UPDATE THE WEBSITE WITH GITHUB DESKTOP

1. Extract the ZIP.
2. Open the extracted sarthakchadha.com folder. Copy its CONTENTS into
   the existing website repository folder, replacing matching files.
   Keep your existing repository and its Git history. Do not put the
   entire extracted folder inside the repository as an extra subfolder.
3. Confirm that docs/projects/communication-systems/index.html and its
   assets folder are included in your GitHub Desktop changes.
4. Commit and push to the branch used by your website.
5. For your existing branch-based GitHub Pages setup, retain main /docs
   as the publishing source and sarthakchadha.com as the custom domain.
6. Wait for the website deployment to finish, then press Ctrl+Shift+R.

No Node.js installation or local build is required to publish this ZIP.

FUTURE SOURCE EDITS

For React/TypeScript changes to the Communication Systems app, first run:

Then from the repository root:
  npm run build:all

Commit the changed sources AND the regenerated root docs folder.
The inner apps/communication-systems/docs folder is the standalone app
export. The root docs/projects/communication-systems folder is the copy
that your website publishes. build:all updates both in order.
